# 🛡️ Advanced Cybersecurity Lab: Sniffing, Phishing & Detection (CEH Project)

## 📌 Overview

This repository showcases a structured hands-on cybersecurity project focused on understanding both offensive and defensive security mechanisms. The project simulates real-world attack scenarios such as phishing and credential harvesting while also implementing detection techniques using industry tools.

This work was completed as part of a multi-week practical learning journey aligned with CEH (Certified Ethical Hacker) concepts.

---

## 🧠 Problem Statement

Modern cyber attacks do not always rely on exploiting system vulnerabilities. Instead, attackers exploit human behavior using techniques such as phishing, social engineering, and credential harvesting.

This project aims to:

* Simulate attacker methodologies
* Analyze network-level data
* Detect and prevent phishing attacks

---

## 📅 Project Timeline (Structured Learning)

### Week 1–2: Network Sniffing & Traffic Analysis

* Captured live packets using Wireshark
* Compared HTTP vs HTTPS traffic
* Observed plaintext credential exposure in HTTP

### Week 3: MITM & ARP Spoofing Concepts

* Understood packet redirection techniques
* Learned how attackers intercept communication

### Week 4: Phishing Simulation (SET Toolkit)

* Launched Social Engineer Toolkit
* Performed Website Cloning (Credential Harvester)
* Created phishing scenario and captured credentials

### Week 5: Phishing Detection (Netcraft)

* Installed Netcraft extension 
* Analyzed site reputation, risk rating, and hosting details
* Observed real-time phishing detection alerts

### Week 6: Phishing Verification (PhishTank)

* Used PhishTank database 
* Verified phishing URLs
* Analyzed reported phishing cases

---

## 📊 Observations & Metrics

* HTTP traffic exposes sensitive data in plaintext
* HTTPS ensures encryption but does not prevent phishing
* Phishing success depends on user trust, not technical flaws
* Netcraft provides:

  * Risk rating
  * Site reputation
  * Hosting details
* PhishTank confirms phishing via community validation

---

## 🔐 Security Insights

* Human behavior is the primary attack surface
* URL inspection is critical for prevention
* Browser-based tools significantly reduce phishing risk
* Multi-layered defense (tools + awareness) is essential
